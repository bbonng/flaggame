# FLAG GAME 기록 저장소 설정 (한 번만, 10분)

수업용 작전 저장소(공간작전판·계획서)는 **그대로 두고**, 게임 기록만 받는 **새 시트**를 따로 만듭니다.

## 1. 시트 만들기
1. 구글 드라이브에서 **새 구글 시트** → 이름 `FLAG GAME 기록`
2. **[확장 프로그램 > Apps Script]** → 원래 코드를 지우고 이 폴더의 `Code.gs`를 통째로 붙여 넣고 **저장(💾)**

## 2. 처음 설정
1. 시트로 돌아와 **새로고침** → 위 메뉴 **[FLAG GAME > 처음 설정]**
2. 권한 창: 계정 선택 → "확인하지 않은 앱"이 나오면 **[고급] → [(프로젝트)(으)로 이동] → [허용]**
3. 나온 **교사 열쇠**를 적어 둡니다 (나중에 [FLAG GAME > 교사 열쇠 보기])
   - 수업용 작전 저장소의 교사 열쇠와는 다른 새 열쇠예요.

## 3. 웹 앱으로 배포
1. **[배포 > 새 배포]** → 유형 **웹 앱**
2. 다음 사용자로 실행: **나** / 액세스 권한: **모든 사용자**
3. **[배포]** → **웹 앱 URL**(`https://script.google.com/macros/s/…/exec`) 복사

## 4. 연결
- 웹 앱 URL을 Claude에게 보내 주시면 게임(`index.html`)과 순위표(`board.html`)에 넣어 드려요. 그러면 학생 기기는 따로 설정할 게 없어요.
- 순위표는 처음 열 때 주소·교사 열쇠를 한 번 넣으면 그 TV(브라우저)가 기억해요.

## 쓰면서 알아 두실 것
- 학생: `https://bbonng.github.io/flaggame/?q=1104` → 반·번호·이름 넣고 경기 (비우면 연습 경기)
- TV: `https://bbonng.github.io/flaggame/board.html?q=1104`
- 순위 = 랭킹 점수(점수 × 루키 1 · 주전 1.5 · 프로 2 · 올스타 3), 한 사람은 최고 기록 1개만
- 장난 기록: [게임기록] 시트 그 줄의 `숨김`을 `TRUE`로
- 기록 받기 멈추기: [설정] 시트 `기록마감`에 `8,9`(그 반만) 또는 `all`
- 코드를 고친 뒤에는 **[배포 > 배포 관리 > ✏️ 수정 > 새 버전]**으로 (주소 그대로)
