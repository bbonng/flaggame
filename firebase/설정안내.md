# 대전 모드 Firebase 설정 (한 번만, 15분)

FLAG GAME 대전 모드는 **Firebase Realtime Database + 익명 로그인**을 씁니다. 무료(Spark) 요금제로 충분합니다.
학생 이름은 저장하지 않습니다. 수업용 작전 저장소·FLAG GAME 점수 시트와는 따로입니다.

## 1. 프로젝트 만들기
1. https://console.firebase.google.com → **프로젝트 추가** (개인 구글 계정)
2. 이름 예: `flaggame-vs` · Google 애널리틱스는 **사용 안 함**

## 2. 익명 로그인 켜기
1. 왼쪽 **빌드 → Authentication → 시작하기**
2. **로그인 방법** 탭 → **익명** → 사용 설정 → 저장
3. **설정 → 승인된 도메인**에 `bbonng.github.io`가 있는지 확인 (없으면 추가)

## 3. Realtime Database 만들기
1. **빌드 → Realtime Database → 데이터베이스 만들기**
2. 위치: 아시아(싱가포르, `asia-southeast1`)가 있으면 그것, 없으면 기본값
3. 보안 규칙: **잠금 모드**로 시작
4. 만든 뒤 **규칙** 탭 → 이 폴더의 `database.rules.json` 내용을 통째로 붙여 넣고 **게시**
   (연결 확인용 `ping`, 대전 방 `rooms`, 수비의 비공개 선택 `picks` 규칙이 들어 있습니다. **이 파일이 바뀌면 다시 붙여 넣고 게시**해야 합니다.)

## 4. 웹 앱 등록 → 설정값 받기
1. 프로젝트 개요 옆 톱니 → **프로젝트 설정 → 내 앱 → 웹(</>)**
2. 앱 닉네임 예: `flaggame` · Hosting은 체크하지 않음
3. 나오는 `const firebaseConfig = { … }` 부분을 복사
   - `databaseURL`이 없으면 3번(Realtime Database)을 먼저 만든 뒤 이 화면을 새로 고치세요.
   - 이 값은 비밀번호가 아닙니다(페이지에 공개돼도 됨). 누가 무엇을 읽고 쓸지는 3-4의 보안 규칙이 막습니다.

## 5. 학교 웨일북에서 확인
1. `https://bbonng.github.io/flaggame/ping.html` 열기
2. **설정값 넣기** → 복사한 내용 붙여 넣기 → 저장하고 확인
3. 위에 **연결됨**(초록)이 뜨면 성공. 두 번째 기기에서도 열면 "지금 열어 둔 기기 수"가 2로 같이 바뀌어야 합니다.
4. 빨간 칸이 나오면 그 줄의 안내를 따르거나 **결과 복사**로 내용을 보내 주세요.

붙여 넣은 설정값은 그 기기에만 저장됩니다. 확인이 끝나면 설정값을 전달해 주시면 `ping.html`·대전 화면에 넣어 학생 기기에서는 따로 붙여 넣지 않게 하겠습니다.

## 무료 요금제에서 기억할 것
- **동시 접속 100개**까지. 넘으면 새 접속이 거절됩니다 → 한 번에 **한 반만** 사용.
- 서버 코드(Cloud Functions)는 쓰지 않습니다(무료 요금제에서 안 됨).
