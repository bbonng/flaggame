# FLAG GAME

플래그풋볼 5v5 **4다운 터치다운 게임**. [공간작전판(flagboard)](https://github.com/bbonng/flagboard) v12의 판정·수비 움직임·3D 엔진을 그대로 쓰고, 그 위에 경기 진행을 올렸습니다.

## 규칙
- 하프라인(골까지 25야드)에서 시작해 **공격 4번** 안에 엔드존으로
- 한 경기 = **드라이브 5번**
- 터치다운 6점, 첫 공격에 바로 터치다운하면 +1
- 터치다운 뒤 추가 득점: 5야드에서 1점 / 12야드에서 2점 (기회 한 번)
- 공은 실시간: 플레이 중에 리시버를 눌러 던짐 (멈추기·되감기 없음)
- 쳐냄 = 제자리, 색 = QB가 잡힌 자리로 후퇴

## 수비 코치
남은 거리와 몇 번째 공격인지 보고 대형을 고릅니다 (골라인 앞 → 4 어크로스·맨, 멀리 남은 3·4번째 → 3-1, 4번째 → 블리츠 늘림 …).
**문제 번호**가 같으면 같은 상황에서 누구나 같은 수비를 만납니다.

## 난이도
| | 수비 반응 | 러셔 | 재생 속도 | 보조선 | 특수 |
|---|---|---|---|---|---|
| ★ 루키 | 0.40초 | 3.4초 | 0.6배 | 공간+던질 곳 | 수비 코치 말 보임 |
| ★★ 주전 | 0.30초 | 3.0초 | 0.8배 | 공간만 | 수비 코치 말 보임 |
| ★★★ 프로 | 0.22초 | 2.7초 | 1배 | 없음 | 위장(35%), 존 구역 숨김 |
| ★★★★ 올스타 | 0.15초 | 2.5초 | 1배 | 없음 | 위장(50%) + 같은 라우트 3번째부터 수비가 읽음 |

랭킹 점수 = 점수 × (1 / 1.5 / 2 / 3)

## 주소로 문제 내기
`index.html?q=1104&lv=2` → 문제 1104, 주전으로 시작 화면이 맞춰집니다.

## 교실 순위표
- 학생: 시작 화면에 반·번호·이름 → 경기를 끝내면 점수가 자동으로 올라감 (비우면 연습 경기)
- TV: `board.html?q=1104` → 문제 번호·교사 열쇠 → 5초마다 새로고침, 순위가 바뀌면 올라가는 애니메이션, 새 1위 축하
- 순위 = 랭킹 점수(점수 × 난이도 배율), 한 사람은 최고 기록 1개
- 저장소: 공간작전판과 같은 Apps Script (`bbonng/flagboard`의 `apps-script/Code.gs`, `score_submit`·`score_board`)
- 못 보낸 기록은 기기에 남았다가 다음에 다시 보냄
